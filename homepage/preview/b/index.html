7d81aafeat: daily work04

写、找、整理、同步，
一天都用得上。

没有花哨的功能清单，只有每天真的会按的按钮。

01

发布与编辑

Ctrl + Enter 快捷发布，每帖最多 9 张图，粘贴截图即可上传。附件单个 10MB 以内、每帖 9 个以内，原始文件名保留。

02

标签与置顶

每帖可打多个标签，点标签一键筛选。重要笔记可置顶钉住，最多 9 篇，钉住清单随同步走，所有设备一致。

03

全库搜索

毫秒级搜索本地仓库全部笔记，关键词 AND 组合，命中高亮。支持拼音与首字母，输入 biji 或 bj 都能命中「笔记」。

04

多端同步

每次写操作自动完成拉取、写入、提交、推送。优先 rebase 保持历史线性，不行再 merge；真冲突会提示「冲突待处理」，不会静默丢数据。

05

AI 助手

配置你自己的 API Key，多端共享。20 多种工具操作，批量删除超过 5 篇时，无论什么模式都强制人工确认。

06

本地安全

服务只监听 127.0.0.1，凭证使用随机 cookie 加 Host 校验。SSH 使用专用 ed25519 密钥，私钥权限 0600。

02

选模式

仅本机绑定远端

仅本机：一个 git init 就开始用，数据只在本机。绑定远端：多设备同步，顺手多一份云端备份。

03

绑定远端

ssh-ed25519 AAAA…git@gitee.com:you/notes.git

把公钥粘贴到 git 服务商的 SSH 设置，再把仓库 SSH 地址贴进绑定向导。之后打开即最新，发布自动同步。

e2a7b1docs: faq07

你可能还想知道。

换电脑了，笔记怎么迁移？

新设备安装 Git笔记，绑定同一个远端仓库，自动拉取全部笔记与历史。整个过程就是一次 git 克隆。

远端服务商可以换吗？

可以。换个仓库地址重新绑定即可，数据是标准 git 仓库，原样带走。

笔记是什么格式？

普通 Markdown 文件，按 micro/年/月/日期-时间.md 存放，任何编辑器都能打开。

不用远端会丢数据吗？

不会。仅本机模式下数据就在你电脑里，配合 git 历史依然可以追溯和恢复。远端只是额外的备份与同步手段。

误删了笔记怎么办？

每一步操作都是 git 提交，历史里都在。可以让 AI 查 git 历史并恢复旧版本，熟悉 git 的也能直接用命令找回。

AI 功能需要联网吗？

AI 对话需要联网调用大模型服务，需自行配置 API Key；但笔记数据始终留在本地，由本机代理按需读取。

多设备同时改会冲突吗？

正常先后使用几乎不会冲突，自动 rebase 整合。真冲突时会明确提示「冲突待处理」，由你选择以本地为准强制推送。
