它是什么

一款笔记应用，
数据是一座 git 仓库。

不是把笔记锁进某个云服务的数据库，而是写成普通文件，放在你自己的文件夹里。

01

一个普通文件夹

打开、复制、备份都行。卸载软件，文件夹还在。换一台电脑，把这个文件夹带走就行。

功能

写、找、整理、同步，
一天都用得上。

发布与编辑

写完直接发，Ctrl + Enter 快捷发布。每帖最多 9 张图，粘贴截图即可上传；附件单个 10MB 以内、每帖 9 个以内，原始文件名保留。超过 10 行自动收起，字号 10 到 50px 可调。

标签与整理

每帖可打多个标签，发布时点选或自定义；点标签一键筛选。重要笔记可置顶钉住，最多 9 篇，钉住清单随同步走，所有设备一致。

全库搜索

毫秒级搜索本地仓库全部笔记，多个关键词 AND 组合，命中内容高亮。支持拼音与首字母，输入 biji 或 bj 都能命中「笔记」，内置 8105 常用字拼音表。

多端同步

每次写操作自动完成拉取、写入、提交、推送，推送被拒自动整合重试。优先 rebase 保持历史线性，不行再 merge；真冲突会提示「冲突待处理」，由你决定，不会静默丢数据。

AI 助手

配置你自己的大模型 API Key，多端共享。AI 能搜索、筛选、阅读笔记，批量创建、修改、删除，按标签整理，查询 git 历史，共 20 多种工具操作。批量删除超过 5 篇时，无论什么模式都强制人工确认。

安全

服务只监听本机 127.0.0.1，不暴露局域网与公网；页面凭证使用随机 cookie 加 Host 校验。SSH 使用专用密钥，自动生成 ed25519，不复用你的 ~/.ssh，私钥权限 0600。

数据格式

零锁定，永远是纯文本

每帖一个 Markdown 文件，任何编辑器、任何 git 工具都能直接读写。就算有一天不用 Git笔记了，笔记还是你的笔记。

      ← 标签、钉住、AI 配置
快速上手

三步，开始记。

不需要注册账号，不需要配置服务器。先记起来，之后再决定要不要同步。

01

安装

Windows 运行安装包 git-notes-x.x.x-setup.exe；Android 装 APK。Web 版目前仅用于测试，需要 Node.js 18 以上和 git。

02

选个模式

首次启动出现引导页。想先记起来，选仅本机，一个 git init 就开始用；需要多设备同步，选绑定远端。

03

绑定远端

设置页点「查看公钥」，粘贴到 Gitee 或 GitHub 的 SSH 设置；新建一个空仓库，复制 SSH 地址贴进绑定向导，点连接。

之后日常使用无需任何操作：打开即最新，发布自动同步。

问答

你可能还想知道。

换电脑了，笔记怎么迁移？

新设备安装 Git笔记，绑定同一个远端仓库，自动拉取全部笔记与历史。整个过程就是一次 git 克隆。

远端服务商可以换吗？

可以。换个仓库地址重新绑定即可，数据是标准 git 仓库，原样带走。

笔记是什么格式？

普通 Markdown 文件，按 micro/年/月/日期-时间.md 存放，任何编辑器都能打开，永远不会有格式锁死的问题。

不用远端会丢数据吗？

不会。仅本机模式下数据就在你电脑里，配合 git 历史依然可以追溯和恢复。远端只是额外的备份与同步手段。

误删了笔记怎么办？

每一步操作都是 git 提交，历史里都在。可以在 AI 助手里让它查 git 历史并恢复旧版本，熟悉 git 的也能直接用命令找回。

AI 功能需要联网吗？

AI 对话需要联网调用大模型服务，需自行配置 API Key；但你的笔记数据始终留在本地，由本机代理按需读取。

多设备同时改会冲突吗？

正常先后使用几乎不会冲突，自动 rebase 整合。真冲突时会明确提示「冲突待处理」，由你选择以本地为准强制推送，不会静默丢数据。
