欢迎使用 Git笔记

绑定 Git 仓库 · 多设备同步

① 复制公钥

这是这台设备的「身份钥匙」，贴到 Git 网站上，网站才信任这台设备。

② 去 Git 网站设置：添加公钥 + 新建仓库

任选一个你有账号的网站，点链接直达：

Gitee 添加公钥 ↗ 新建仓库 ↗
GitHub 添加公钥 ↗ 新建仓库 ↗
阿里云 Codeup 添加公钥 ↗ 新建项目 ↗

⚠ 仓库必须设置为「私有（Private）」！否则你的笔记对全网公开可见。

新建时保持空仓库（不要勾选「初始化 README」）；建好后进入仓库页面，把 SSH 地址复制下来，形如 git@gitee.com:you/notes.git。其他 Git 网站也一样：设置里找「SSH 公钥」，新建仓库后拷 SSH 地址。

③ 粘贴仓库地址，连接

⚠ 务必粘贴 SSH 地址（形如 git@gitee.com:you/notes.git），不要粘贴 https:// 地址！

熟悉 Git？直接填地址即可。
